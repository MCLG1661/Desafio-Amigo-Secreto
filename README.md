Desenvolvida para realizar **sorteios de Amigo Secreto** de maneira simples e interativa.

O projeto permite cadastrar participantes, gerenciar a lista de nomes e realizar o sorteio utilizando **JavaScript**, aplicando conceitos fundamentais de lógica de programação, manipulação do DOM e interação com o usuário.

É o Trabalho Final da Tech Foundation 1, segunda Fase do ONE G9 BR e fez parte da minha trajetória no programa **Oracle Next Education (ONE) — G9 BR**.

## English Overview

A JavaScript web app for managing a participant list and drawing a name for Secret Santa. Built for Oracle Next Education (ONE) G9 BR, it demonstrates programming logic, DOM manipulation, and interactive input handling.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma aplicação Front-end capaz de gerenciar participantes e realizar um sorteio aleatório, utilizando tecnologias fundamentais da Web.

Além da funcionalidade principal, o projeto foi utilizado para praticar conceitos de **lógica de programação e desenvolvimento Front-end**.

---

## ✨ Funcionalidades

A aplicação permite :

- ➕ Adicionar participantes
- 📋 Visualizar os nomes cadastrados
- 🗑️ Remover participantes
- 🎲 Realizar o sorteio aleatório
- 🔄 Reiniciar o sorteio
- 🧹 Limpar a lista de participantes
- 📱 Utilizar a aplicação em diferentes tamanhos de tela

## 🧠 Como Funciona

O fluxo principal da aplicação é simples :

```text
Usuário
   ↓
Adicionar participantes
   ↓
Validar os nomes
   ↓
Exibir lista
   ↓
Realizar sorteio
   ↓
Selecionar participante aleatoriamente
   ↓
Exibir resultado
```

A lógica de interação e sorteio é executada diretamente no navegador utilizando JavaScript.

## 🚀 Como Executar

1. Clone o repositório

```bash
git clone https://github.com/MCLG1661/Desafio-Amigo-Secreto.git
```

2. Entre no diretório

```bash
cd Desafio-Amigo-Secreto
```

3. Execute a aplicação

Abra o arquivo:

```text
index.html
```

em um navegador moderno.

Também é possível utilizar uma extensão como **Live Server** durante o desenvolvimento.

---

## 🎮 Como Usar

1. Digite o nome de um participante.
2. Adicione o nome à lista.
3. Repita o processo para cadastrar os demais participantes.
4. Confira a lista antes de realizar o sorteio.
5. Clique no botão correspondente para sortear.
6. O resultado será apresentado na interface.
